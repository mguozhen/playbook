⚠️ 为什么这套和 MVP 完全不同

核心矛盾

Amazon 关联检测 13 个维度叠加 TT/IG 风控 = 单台失误拖累整组。MVP 4 台烧坏没关系，50 台连环烧 = 灾难。

目标转换

不再是 90 天找信号，是 6-12 个月养出 50 个可长期持有的数字身份。账号本身就是资产。

预算量级

$30k-$50k 起步。设备 $10k 只是入门，地址 / SIM / 主体 / IP 加起来才是大头。

运营节奏

每号每周登 1-3 次，每次 5-15 分钟。50 个号不能同时活跃，要分批轮转。

主体结构

需要 2-3 个 LLC 隔离风险。1 个 LLC 挂 50 个号 = Amazon 一关全关。

变现≠主目标

保号期可零变现。Amazon 老买家号 5 年后单价 ¥2k-5k，提前急吼吼变现会摧毁资产。

🛡️ Amazon 关联检测 13 维度防御

Amazon 是三平台中风控最严的。13 个关联维度任一被关联，可能触发"挂联"封禁所有相关账号。每台手机必须独立守住这 13 维。

01
设备指纹
IMEI / Serial / Advertising ID / Hardware ID 每台独立。出厂状态使用，不刷机不 root。
02
出口 IP
每台独立 SIM 蜂窝数据，不连任何 WiFi。Tello / Mint Mobile / US Mobile 真实运营商 IP。
03
付款方式
每号一张 Privacy.com 虚拟卡，绑不同 Plaid 来源。不要复用同一信用卡。
04
收货地址
10-20 个虚拟邮箱地址（Anytime Mailbox / US Global Mail）。每地址挂 3-5 个账号上限。
05
浏览器 Cookie
每号独立 Safari/Chrome profile，清干净 LocalStorage / IndexedDB。每月手动清一次。
06
邮箱关联
不同 Gmail 域名、不同 recovery email、不交叉互为 backup。50 个号 = 50 个 Gmail。
07
手机号
每号独立 Tello SIM。不用 Google Voice / Twilio 虚拟号（Amazon 拒）。
08
行为模式
购物时段错开、品类风格独立。50 个号都买同款 = 立刻挂联。
09
退货历史
退货率 < 5%。同一邮箱多次申诉触发 review。
10
Wi-Fi BSSID
即使你"只用蜂窝"，App 仍可能扫到周围 WiFi。家里别开过多设备同 Wi-Fi。
11
设备型号
50 台同款 iPhone 11 = 风控扫到"同批购入"概率。建议混搭 2-3 个型号。
12
登录时序
50 个号 24 小时内全部首次登 Amazon = 必挂联。分 30 天逐批激活。
13
主体（LLC）
2-3 个 LLC 分组挂号。1 个 LLC 挂 50 号 = Amazon 关联秒挂全组。

🌐 50 个静态商业 IP 的应用方案

你已有的 50 个静态商业 IP（数据中心 IP）不能用于 TT/IG/Amazon，但完美匹配 Reddit 矩阵 + 辅助任务。

✅ 适合用

Reddit 矩阵：50 profile × 50 IP，1:1 绑定。Reddit 对数据中心 IP 容忍度高。

AdsPower 启动：每个 profile 默认走分配的静态 IP。

邮箱注册：Gmail / ProtonMail / iCloud Mail 注册可走（频繁要手机验证但能过）。

Playwright 监控：监控 subreddit / TT trending / Amazon 价格（不登录）。

❌ 不能用

Instagram：注册阶段直接拒（IG 对 IDC IP 零容忍）。

Amazon：注册即被标 fraud · 号秒挂。

TikTok 国际版：限流 · 新号信任分极低 · 不要碰。

Apple ID 注册：Apple 对 IDC IP 风控严，多次失败会锁。

关键纪律

  • 50 个静态 IP 不能与任何 Amazon 真机矩阵的设备共享（哪怕一次都不行）
  • 真机矩阵的 iPhone 全程仅蜂窝数据（Tello SIM），不连任何 WiFi · 也不能通过 Mac 主控的网络共享出口
  • Mac 主控自身的 WiFi 网络 不能跑 AdsPower（避免静态 IP 和真机 BSSID 关联）
  • 静态 IP 信誉必须先跑 ~/matrix-mvp/scripts/check_ip_reputation.sh 检测黑名单 · 不干净的换

⚙️ 一机三号 · 日常 SOP

核心原则：50 个号不能同时活跃

同时 50 个号活跃 = 同一物理空间 50 个用户行为聚类 = 立即触发关联。必须分批轮转。

推荐节奏：5 天循环 · 每天 10 台活跃

Day 1

#01-#10 活跃 · 各自 TT/IG 浏览 + 偶尔 Amazon

Day 2

#11-#20 活跃

Day 3

#21-#30 活跃

Day 4

#31-#40 活跃

Day 5

#41-#50 活跃

每月 1 次

50 台全部"轻摸"一次（开机检查更新，不操作账号）

每台单日操作 SOP（15-20 分钟）

  • TT：刷 10-15 分钟 For You · 点 2-3 个赞 · 偶尔评论一条 · 每周发 1-2 条原创（视号定位）
  • IG：刷 Reels 5 分钟 · 看 1-2 个 story · 偶尔点赞 · 每 2-3 周发 1 张图
  • Amazon：每月浏览 2-3 次 · 每 2-3 月下一笔小单（$15-50）· 留 verified purchase 痕迹

禁忌

  • 同一时段不要切换 5+ 台手机（让户主活动看起来"是一个人"）
  • 不要在同一台手机上让 TT/IG/Amazon 跳来跳去（每次只用一个 App，留间隔 5-10 分钟）
  • Amazon 不要批量下同款商品（哪怕每号都买相同产品，分散日期）
  • 不要给同样的产品留好评（明显的刷单痕迹）
